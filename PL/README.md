| **Ruby**            | `#`          | `=begin ... =end`     | `#` (YARD)              |
| **Go**              | `//`         | `/* */`               | `//` (godoc)            |
| **Rust**            | `//`         | `/* */`               | `///` 文档注释，`//!` 模块文档 |
| **Swift**           | `//`         | `/* */`               | `///` 或 `/** */`        |
